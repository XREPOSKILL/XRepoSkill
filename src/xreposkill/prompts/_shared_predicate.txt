PREDICATE (REQUIRED when kind is "action"): every action rule MUST carry an
executable predicate, a test of whether an arbitrary trajectory exhibits the
behavior the rule prescribes. A rule that cannot be tested on other
trajectories is not admitted. The predicate is a DSL expression over the
trajectory's event sequence:
  events:  read | search | edit | run_test | run_python | install | git |
           submit | any, optionally with a regex matched against the full
           bash command: run_test("test_separable"), search("def "),
           any("saferepr"). Quote the pattern with double quotes;
           `first_edit` names the first edit event.
  atoms:   exists(E) | before(E1, E2) | after(E1, E2) | count(E) >= n
  logic:   and | or | not | parentheses
Examples:
  before(run_test, first_edit)              reproduced before the first edit
  before(search("def "), first_edit)        inventoried definitions first
  after(run_test, first_edit) and count(run_test) >= 2
The predicate must describe the PROCESS the rule prescribes, never the bug's
location or the patch content. It is executed on about 6000 trajectories of
the pool; a predicate that is true for almost all (>90%) or almost none
(<10%) of them is rejected as untestable, so prefer patterns tied to the
rule's distinctive behavior over trivially true ones. A fact rule may carry
a predicate when one applies, or null.

COMMON PREDICATE MISTAKES (each has caused a rejection):
  WRONG exists(before(run_test, first_edit))   atoms cannot nest inside an
        event slot; events are only the 9 types.
  RIGHT before(run_test, first_edit)
  WRONG search('saferepr')                     single quotes do not parse.
  RIGHT search("saferepr")
  WRONG count(any("x") or any("y")) >= 1       no logic inside count/exists.
  RIGHT exists(any("x")) or exists(any("y"))
  WRONG search("def get_del_batches")          a symbol unique to THIS bug
        occurs in about 0% of the pool trajectories and is rejected as
        untestable. An action rule's predicate must describe the shape of
        the behavior, for example before(search("def "), first_edit).
        (A fact rule may keep concrete symbols.)
